# 투표 · 결과

투표 시작부터 결과 발표, 이마 톡톡, 연속 지목 휴식까지 다룹니다. 회차 상태와 투표 명단은 [`common.md`](common.md)를 따릅니다.

## VOTE-01 투표 시작

상태: 미구현

### 기능 설명
전원 인증 또는 자정에 투표를 시작하고 명단과 판정 데이터를 고정한다.

### 입력
- 방의 현재 회차
- 활성 멤버와 인증 상태
- 리액션 목탁 수
- 휴식 상태
- 방어권 사용 상태

### 처리 규칙
1. 활성 멤버 전원이 인증하면 즉시 시작한다. 전원에는 그날 들어온 멤버와 휴식 중인 멤버도 포함한다. [정책서]
2. 전원 인증이 아니면 자정에 시작한다. [정책서]
3. 시작 시점 활성 멤버를 투표 명단으로 저장한다. [정책서]
4. 명단이 3명 미만이면 투표를 생성하지 않고 회차를 `투표 없음`으로 바꾼 뒤 친구 초대 상태를 반환한다. [정책서]
5. 인증·목탁 수·휴식 상태를 결과 판정용으로 고정한다. 방어권은 마지막 인증자 유예(SHIELD-02 7번) 때문에 고정하지 않고 결과 판정 시점에 읽는다. [구현 결정]
6. 자정 전에 시작하면 방 멤버에게 투표 열림 알림을 보낸다. [정책서]

### 출력
- 투표 회차
- 명단 및 후보 스냅샷
- 마감 예정 시각

### 예외
- 동일 시작 조건을 여러 서버가 처리해도 투표는 하나만 생성한다.

### 제외 범위
- 후보 계산 (VOTE-02)
- 투표 열림 알림 발송 (NOTI-02)

### 완료 조건

**VOTE-01-1 전원 인증하면 바로 시작**
- Given 활성 멤버 4명(오늘 들어온 1명, 휴식 중 1명 포함) 중 3명이 인증한 `인증 중` 회차
- When 남은 1명이 인증하면
- Then 즉시 투표가 시작되고 명단은 4명이다

**VOTE-01-2 전원 인증이 아니면 자정에 시작**
- Given 활성 멤버 4명 중 2명이 인증한 회차
- When 자정이 되면
- Then 투표가 시작되고 마감 예정 시각은 다음 날 12:00이다

**VOTE-01-3 3명 미만이면 투표 없음**
- Given 활성 멤버가 2명인 방
- When 자정이 되면
- Then 투표를 만들지 않고 회차는 `투표 없음` 상태가 되며 친구 초대 상태를 반환한다

**VOTE-01-4 판정 데이터 고정**
- Given A의 인증에 목탁이 3개 있는 상태에서 투표가 시작됐다
- When 투표 중에 B가 A의 인증에 목탁을 남기면
- Then 리액션은 거부되고 판정에 쓰는 A의 목탁 수는 3개다

**VOTE-01-5 동시 시작 요청**
- Given 마지막 인증 처리와 자정 작업이 같은 회차에 동시에 실행된다
- When 둘 다 투표 시작을 시도하면
- Then 투표는 하나만 생성된다

**VOTE-01-6 자정 전 시작 알림**
- Given 23:00에 남은 1명만 인증하면 전원 인증이 된다
- When 그 1명이 인증해 투표가 시작되면
- Then 방 멤버에게 투표 열림 알림을 보낸다
- 참고: 자정 작업으로 시작할 때 알림을 보내는지는 아직 정하지 않았다. [미정] Q-24

## VOTE-02 후보 결정

상태: 미구현

### 기능 설명
투표자마다 본인을 뺀 후보를 제공한다. 휴식 중인 사용자는 선택할 수 없게 표시한다.

### 입력
- 투표 명단
- 인증 상태
- 휴식 상태

### 처리 규칙
1. 투표 명단의 멤버를 기본 후보로 한다. [정책서]
2. 투표자 본인은 후보에서 제외한다. [정책서]
3. 휴식 중인 멤버는 후보 목록에 `휴식 중`으로 표시하되 선택할 수 없다. [WF 22]
4. 기존 멤버의 미인증은 후보에 포함한다. [정책서]
5. 투표 시작 이후 참여한 멤버는 명단과 후보에서 제외한다. [정책서]
6. 후보와 별도로 `오늘은 모두 보살`을 항상 제공한다. [정책서]
7. 그날 들어와서 인증하지 않은 멤버는 후보에서 제외한다. [정책서]

### 출력
- 후보의 보살·닉네임
- 인증 상태와 인증 내용
- 투표 시작 시점 목탁 수
- 후보별 선택 가능 여부와 불가 사유(`휴식 중`)
- `오늘은 모두 보살`

### 예외
- 후보가 한 명뿐이어도 `오늘은 모두 보살`을 선택할 수 있다.

### 제외 범위
- 투표 제출 검증 (VOTE-03)

### 완료 조건

공통 Given: 명단은 A, B, C, D이고 A가 투표자다.

**VOTE-02-1 본인 제외**
- When A가 후보를 조회하면
- Then B, C, D와 `오늘은 모두 보살`이 나오고 A는 없다

**VOTE-02-2 본인 투표 서버 차단**
- When A가 A에게 투표하는 요청을 직접 보내면
- Then 서버가 거부한다

**VOTE-02-3 휴식 중 표시**
- Given C가 휴식 중이다
- When A가 후보를 조회하면
- Then C는 `휴식 중`, 선택 불가로 나온다

**VOTE-02-4 휴식 중 투표 서버 차단**
- Given C가 휴식 중이다
- When A가 C에게 투표하는 요청을 직접 보내면
- Then 서버가 거부한다

**VOTE-02-5 기존 멤버 미인증은 후보**
- Given 기존 멤버 B가 인증하지 않았다
- When A가 후보를 조회하면
- Then B는 선택 가능한 후보다

**VOTE-02-6 오늘 들어온 미인증 멤버 제외**
- Given D가 오늘 들어왔고 인증하지 않았다
- When A가 후보를 조회하면
- Then D는 후보에 없다

**VOTE-02-7 시작 후 참여자 제외**
- Given 투표 시작 뒤 E가 방에 들어왔다
- When A가 후보를 조회하면
- Then E는 명단과 후보에 없다

**VOTE-02-8 후보가 한 명뿐일 때**
- Given B만 선택 가능한 후보다
- When A가 후보를 조회하면
- Then A는 B 또는 `오늘은 모두 보살`을 선택할 수 있다

## VOTE-03 투표 제출

상태: 미구현

### 기능 설명
명단 사용자가 후보 또는 `오늘은 모두 보살`에 한 번 투표한다. WF 22·23·59.

### 입력
- 투표 회차 ID
- 선택한 후보 또는 `ALL_BOSAL`

### 처리 규칙
1. 투표 명단에 포함된 사용자만 제출할 수 있다. [정책서]
2. 투표 전에 변경 불가 안내를 확인한다. [정책서]
3. 1인 1표이며 제출 후 변경·취소할 수 없다. [정책서]
4. 본인은 선택할 수 없다. [정책서]
5. 투표 보상은 정상 제출과 함께 한 번만 적립한다. [정책서]
6. `오늘은 모두 보살` 선택에도 같은 보상을 지급한다. [정책서]
7. 마지막 미투표자가 제출하면 즉시 투표를 마감한다. [정책서]
8. 투표 중에는 후보별 득표 수를 공개하지 않는다. 투표한 사람 수와 명단 인원만 공개한다. [정책서] [WF 24]
9. 투표 시작 뒤 나갔다가 다시 들어온 멤버는 이번 회차에 투표할 수 없다. 나가기 전에 이미 낸 표는 유지한다. [PRD]

### 출력
- 투표 완료 상태
- 개인 +5석, 방 솥 +5석 적립 결과
- 결과 공개 여부

### 예외
- 중복 제출: 기존 표를 유지하고 추가 보상을 지급하지 않는다.
- 마감 후 제출: 결과 상태를 반환한다.

### 제외 범위
- 투표 마감 판단 (VOTE-04)
- 공양미 계산 (RICE-01)

### 완료 조건

공통 Given: 명단은 A, B, C, D이고 투표 중이다.

**VOTE-03-1 정상 제출**
- When A가 B에게 투표하면
- Then A는 투표 완료 상태가 되고 A +5석, 방 솥 +5석이 한 번 적립된다

**VOTE-03-2 모두 보살 선택도 같은 보상**
- When A가 `오늘은 모두 보살`을 선택하면
- Then A +5석, 방 솥 +5석이 적립된다

**VOTE-03-3 명단 밖 사용자 거부**
- Given E가 투표 시작 뒤 들어왔다
- When E가 투표하면
- Then 거부한다

**VOTE-03-4 중복 제출**
- Given A가 이미 B에게 투표했다
- When A가 C에게 다시 투표하면
- Then A의 표는 B로 유지되고 추가 보상은 없다

**VOTE-03-5 마감 후 제출**
- Given 투표가 마감됐다
- When A가 투표하면
- Then 표를 저장하지 않고 결과 상태를 반환한다

**VOTE-03-6 투표 중 득표 비공개**
- Given A, B가 투표했다
- When 누구든 투표 현황을 조회하면
- Then `2/4`만 나오고 후보별 득표 수는 없다

**VOTE-03-7 마지막 두 표 동시 제출**
- Given A, B가 투표했다
- When C와 D가 동시에 투표하면
- Then 마감과 결과는 한 번만 생기고 C, D 보상은 각각 한 번이다

**VOTE-03-8 다시 들어온 멤버는 투표 불가**
- Given C가 투표 시작 뒤 방을 나갔다가 다시 들어왔다
- When C가 투표하면
- Then 거부한다

## VOTE-04 투표 마감

상태: 미구현

### 기능 설명
명단 전원 투표 또는 다음 날 정오에 투표를 마감한다.

### 입력
- 투표 명단과 제출된 표
- 현재 시각

### 처리 규칙
1. 명단 전원이 투표하면 즉시 마감한다. [정책서]
2. 미투표자가 있으면 다음 날 12:00에 마감한다. [정책서]
3. 미투표자는 기권 처리한다. [정책서]
4. 마감 후 즉시 결과를 계산한다. [정책서]
5. 마감 전에 나간 명단 멤버가 이미 낸 표는 집계에 포함한다. 투표하지 않고 나간 멤버는 기권으로 보고, 전원 투표 조기 마감은 남은 명단 멤버 기준으로 판단한다. [PRD]

### 출력
- 마감 시각
- 투표 결과
- 결과 미확인 사용자 목록

### 예외
- 아무도 투표하지 않으면 `모두 무사`다.
- 투표 중에 나간 명단 멤버가 후보로 남는지, 지목될 수 있는지는 아직 정하지 않았다. [미정] Q-27

### 제외 범위
- 결과 판정 규칙 (RESULT-01)
- 결과 알림 (NOTI-02)

### 완료 조건

공통 Given: 명단은 A, B, C, D이고 투표 중이다.

**VOTE-04-1 전원 투표 즉시 마감**
- Given A, B, C가 투표했다
- When D가 투표하면
- Then 즉시 마감하고 결과를 계산한다

**VOTE-04-2 정오 마감**
- Given A, B, C가 투표했다
- When 다음 날 12:00이 되면
- Then 마감하고 D는 기권으로 처리한다

**VOTE-04-3 0표**
- Given 아무도 투표하지 않았다
- When 다음 날 12:00이 되면
- Then 결과는 `ALL_SAFE`다

**VOTE-04-4 마지막 투표와 정오 작업 동시 실행**
- Given A, B, C가 투표했다
- When D의 투표와 정오 작업이 동시에 실행되면
- Then 결과는 하나다

**VOTE-04-5 나간 멤버가 낸 표는 유지**
- Given A, B, C가 투표했고 C가 마감 전에 방을 나갔다
- When D가 투표하면
- Then 남은 명단 A, B, D가 모두 투표했으므로 즉시 마감하고, C가 낸 표도 집계한다

**VOTE-04-6 투표하지 않고 나간 멤버는 기권**
- Given A, B가 투표했고 C가 투표하지 않고 방을 나갔다
- When D가 투표하면
- Then 남은 명단 A, B, D가 모두 투표했으므로 즉시 마감하고, C는 기권이다
