# 공양미 · 곳간

공양미(단위: 석) 적립·회수, 방 공동 진행도인 한 솥, 이마 방어권을 다룹니다. 수치는 [`common.md`](common.md)의 핵심 수치를 따릅니다.

## RICE-01 개인 공양미 적립

상태: 미구현

### 기능 설명
인증·투표·한 솥 완성으로 개인 공양미를 적립합니다.

### 입력
- 적립 사유: 인증, 투표, 한 솥 완성
- 원인 ID: 인증 ID, 투표 ID, 솥 ID

### 처리 규칙
1. 방 인원이 2명 이상일 때만 적립한다. [정책서]
2. 인증하면 방마다 회차당 개인 +10석을 지급한다. [정책서]
3. 투표하면 방마다 회차당 개인 +5석을 지급한다. `오늘은 모두 보살`을 골라도 같다. [정책서]
4. `참았어요`와 `못 참았어요`에 같은 양을 지급한다. [정책서]
5. 한 솥이 완성되면 그 시점 방 멤버 전원에게 +30석을 지급한다. (POT-01) [정책서]
6. 잔액은 저장하지 않고 장부(적립·사용·회수 기록)의 합계로 계산한다. [구현 결정]
7. 같은 원인 ID에는 한 번만 지급한다. 인증을 삭제하고 다시 인증하면 새 인증 ID라서 다시 지급한다. [PRD]

### 출력
- 변동량, 사유, 원인 ID
- 변경 후 잔액
- 화면 표시 잔액: 음수면 0석 [WF 33]

### 예외
- 같은 인증·투표로 다시 요청해도 중복 지급하지 않는다

### 제외 범위
- 현금·토스 포인트 전환, 선물, 내기 (제공하지 않음)
- 회수 (RICE-02)
- 사용 (SHIELD-01, ITEM-01)

### 완료 조건

**RICE-01-1 인증 보상**
- Given 방 인원이 3명이다
- When A가 인증하면
- Then A에게 +10석이 기록된다

**RICE-01-2 투표 보상**
- Given 방 인원이 3명이다
- When A가 `오늘은 모두 보살`에 투표하면
- Then A에게 +5석이 기록된다

**RICE-01-3 혼자인 방**
- Given 방 인원이 1명이다
- When A가 인증하면
- Then 공양미를 기록하지 않는다

**RICE-01-4 같은 인증으로 중복 지급 없음**
- Given A의 인증으로 +10석이 기록됐다
- When 같은 인증 ID로 지급이 다시 실행되면
- Then 추가로 기록하지 않는다

**RICE-01-5 삭제 후 다시 인증**
- Given A가 인증해 +10석을 받고, 삭제해 -10석이 회수됐다
- When A가 같은 회차에 다시 인증하면
- Then 새 인증으로 +10석이 기록되고 그 회차 순 지급은 10석이다

**RICE-01-6 음수 잔액 표시**
- Given A의 장부 합계가 -10석이다
- When A가 잔액을 조회하면
- Then 화면 표시 잔액은 0석이다

## RICE-02 공양미 회수

상태: 미구현

### 기능 설명
삭제된 인증으로 지급했던 공양미를 회수합니다.

### 입력
- 삭제된 인증 ID

### 처리 규칙
1. 본인이 인증을 삭제하면 그 인증으로 지급된 개인 공양미를 장부 기록만큼 회수한다. 지급되지 않았으면 회수하지 않는다. [정책서]
2. 진행 중인 솥에 들어간 그 인증의 적립분도 회수한다. [정책서]
3. 이미 완성된 솥에 들어간 적립분은 회수하지 않는다. [정책서]
4. 끝난 투표 결과는 바꾸지 않는다. [정책서]
5. 잔액이 음수가 될 수 있고, 0 이상이 될 때까지 구매를 막는다. [정책서]

### 출력
- 회수 기록

### 예외
- 같은 삭제로 다시 요청해도 회수는 한 번만 기록한다

### 제외 범위
- 운영자 조치에 따른 회수 (신고가 범위에서 빠짐)

### 완료 조건

**RICE-02-1 개인 회수**
- Given A의 인증으로 +10석이 기록됐다
- When A가 인증을 삭제하면
- Then A에게 -10석이 기록된다

**RICE-02-2 지급되지 않은 보상**
- Given 방 인원 1명일 때 인증해 보상이 없었다
- When A가 인증을 삭제하면
- Then 회수를 기록하지 않는다

**RICE-02-3 진행 중인 솥 회수**
- Given A의 인증 10석이 진행 중인 솥에 들어갔다
- When A가 인증을 삭제하면
- Then 솥 진행도가 10석 줄어든다

**RICE-02-4 완성된 솥은 회수 안 함**
- Given A의 인증 10석이 들어간 솥이 이미 완성됐다
- When A가 인증을 삭제하면
- Then 개인 공양미만 회수하고 솥 진행도는 그대로다

**RICE-02-5 음수 잔액**
- Given A의 잔액이 5석이다
- When A의 인증 삭제로 10석을 회수하면
- Then A의 잔액은 -5석이고 구매할 수 없다

**RICE-02-6 회수 중복 없음**
- Given A의 인증 삭제로 회수가 기록됐다
- When 회수가 다시 실행되면
- Then 추가로 기록하지 않는다

## POT-01 공양미 한 솥

상태: 미구현

### 기능 설명
방마다 300석의 공동 진행도를 채웁니다.

### 입력
- 인증·투표 적립, 인증 삭제 회수

### 처리 규칙
1. 방 인원이 2명 이상일 때 인증 +10석, 투표 +5석을 쌓는다. [정책서]
2. 개인 잔액에서 차감하지 않는 별도 진행도다. [정책서]
3. 300석 이상이면 완성 처리한다. [정책서]
4. 완성 시점 방 멤버 전원에게 개인 +30석을 지급한다. [정책서]
5. 방의 쌀가마 배지를 +1 한다. [정책서]
6. 300석을 넘친 값은 새 솥으로 이월한다. [정책서]
7. 솥 진행도는 0 아래로 내려가지 않는다. [정책서]
8. 완성 축하 화면은 사용자마다 한 번만 보여준다. [WF 19]
9. 멤버별로 몇 번째 솥까지 봤는지만 저장하고, 방에 들어올 때 현재 완성 횟수로 채운다. [구현 결정]

### 출력
- 현재 솥 진행도
- 완성 횟수 (쌀가마 배지)
- 이월 석
- 미확인 축하 여부

### 예외
- 동시 적립으로 300석을 넘겨도 완성 보상은 한 번만 지급한다

### 제외 범위
- 개인 공양미 장부 (RICE-01, RICE-02)

### 완료 조건

**POT-01-1 완성과 이월**
- Given 솥 진행도가 295석이다
- When A가 인증해 10석이 들어가면
- Then 솥이 완성되고 멤버 전원에게 +30석, 쌀가마 배지 +1, 새 솥은 5석에서 시작한다

**POT-01-2 동시 적립으로 완성**
- Given 솥 진행도가 295석이다
- When A와 B의 인증 적립이 동시에 들어가면
- Then 완성은 한 번이고 보상도 한 번이며 새 솥은 15석이다

**POT-01-3 0 아래로 안 내려감**
- Given 솥 진행도가 5석이다
- When 10석을 회수하면
- Then 솥 진행도는 0석이다

**POT-01-4 축하는 한 번만**
- Given 솥이 완성됐고 A가 축하 화면을 봤다
- When A가 다시 앱에 들어오면
- Then 축하 화면을 다시 보여주지 않는다

**POT-01-5 들어오기 전 완성은 축하 없음**
- Given 솥이 2번 완성된 방이다
- When E가 방에 들어오면
- Then E에게 축하 화면을 보여주지 않는다
