# 정리 배치

나간 멤버의 기록과 삭제한 사용자를 정리합니다. 인증 사진 삭제는 CERT-04, 쓰이지 않은 업로드 사진은 저장소 수명 주기 규칙을 따릅니다. 모든 배치는 다시 실행해도 안전해야 합니다. 방과 방장 멤버를 한 번에 만들어 빈 방이 생기지 않으므로 CLEAN-03(빈 방)은 비워 둡니다. (Q-37)

## CLEAN-01 떠난 보살 기록

상태: 미구현

### 기능 설명
나간 지 6개월이 지난 멤버의 사진, 한 줄 기록, 쓴 금액을 삭제합니다.

### 입력
- 나간 시각이 있는 멤버

### 처리 규칙
1. 매일 실행한다. [PRD]
2. `left_at + 6개월` 시각이 지난 멤버의 인증에서 남은 사진을 삭제하고 한 줄 기록과 쓴 금액을 비운다. [Q-19]
3. 나간 유형이 `LEFT`, `KICKED`, `DATA_DELETED`인 멤버를 모두 대상으로 한다. [PRD] [Q-44]
4. 투표 결과는 지우지 않고 "떠난 보살"로 남긴다. [Q-19]
5. 6개월 안에 다시 들어온 멤버는 나간 시각이 비어 대상에서 빠진다. (INVITE-03) [PRD]

### 출력
- 없음

### 예외
- 이미 정리한 기록은 다시 실행해도 오류 없이 넘어간다

### 제외 범위
- 회차 종료 7일 뒤 사진 삭제 (CERT-04)
- 사용자 행 정리 (내 데이터 삭제 때 바로 처리, USER-05)

### 완료 조건

**CLEAN-01-1 6개월이 지난 기록**
- Given A가 나간 지 6개월이 지났고 사진, 한 줄, 금액이 있다
- When 배치가 실행되면
- Then A의 사진이 삭제되고 한 줄과 금액이 비워진다

**CLEAN-01-2 6개월이 지나지 않은 기록**
- Given A가 나간 지 5개월 됐다
- When 배치가 실행되면
- Then A의 한 줄과 금액은 그대로다

**CLEAN-01-3 다시 들어온 멤버**
- Given A가 나갔다가 6개월 안에 다시 들어와 현재 멤버다
- When 처음 나간 시각에서 6개월이 지나 배치가 실행되면
- Then A의 기록은 그대로다

**CLEAN-01-4 내 데이터 삭제로 나감**
- Given A가 내 데이터를 삭제한 지 6개월이 지났다
- When 배치가 실행되면
- Then A의 한 줄과 금액이 비워진다

**CLEAN-01-5 다시 실행**
- Given 배치가 이미 A의 기록을 정리했다
- When 배치가 다시 실행되면
- Then 오류 없이 끝난다

**CLEAN-01-6 투표 결과 유지**
- Given A가 지목된 회차가 있고 A가 나간 지 6개월이 지났다
- When 배치가 실행된 뒤 그 회차 결과를 조회하면
- Then 결과와 득표수는 그대로이고 A는 "떠난 보살"로 표시된다

**CLEAN-01-7 내보내진 멤버**
- Given A가 내보내진 지 6개월이 지났고 한 줄과 금액이 있다
- When 배치가 실행되면
- Then A의 한 줄과 금액이 비워진다

## CLEAN-02 내보내기 차단 해시

상태: 구현됨

### 기능 설명
내 데이터 삭제(USER-05) 때 남긴 내보내기 차단 해시를 보관 기간이 지나면 지웁니다. [Q-51]

### 입력
- 만료 시각이 있는 차단 기록

### 처리 규칙
1. 매일 실행한다. [구현 결정]
2. 만료 시각(삭제 시각 + 6개월)이 지난 기록을 지운다. [Q-51]
3. 입장 판단(INVITE-02)은 만료 시각을 직접 비교하므로, 배치가 늦어도 만료된 기록으로 입장을 막지 않는다. [구현 결정]

### 출력
- 없음

### 예외
- 지울 기록이 없으면 아무것도 하지 않는다

### 제외 범위
- 멤버의 한 줄·금액 삭제 (CLEAN-01)
- 사용자 행 정리 (내 데이터 삭제 때 바로 처리, USER-05)

### 완료 조건

**CLEAN-02-1 만료된 기록**
- Given 차단 기록의 만료 시각이 지났다
- When 배치가 실행되면
- Then 그 기록이 지워진다

**CLEAN-02-2 만료 전 기록**
- Given 차단 기록의 만료 시각이 지나지 않았다
- When 배치가 실행되면
- Then 그 기록은 그대로다
