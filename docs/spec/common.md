# 공통 규칙

모든 기능 명세에 공통으로 적용되는 용어, 수치, 시간 기준, 회차 상태입니다.

## 서비스 개요

- 친구 2~4명이 방을 만들어 매일 "오늘 참았는지"를 인증하고, 인증한 친구끼리 "가장 크게 흔들린 보살"을 익명 투표로 뽑는 절약 챌린지
- 뽑힌 사람은 친구들에게 **이마 톡톡**(벌칙 연출)을 받음
- 인증·투표로 **공양미**(단위: 석)를 모아 꾸미기 아이템이나 **이마 방어권**을 삼
- 토스 앱 안의 미니앱(앱인토스)으로 출시. 로그인·약관 동의 화면 없이 토스의 익명 사용자 식별키로 사용자를 구분

## 용어

| 용어 | 뜻 | 서버 |
|---|---|---|
| 보살 | 방 안에서의 내 캐릭터. 방마다 닉네임·색상이 다름 | `room_members` |
| 회차 | 방 하나의 하루. 회차 날짜는 05:00부터 다음 날 04:59까지 (KST). 예) 6/1 04:59 인증은 5/31 회차 | `rounds` |
| 인증 | 회차마다 "참았어요 / 못 참았어요" + 한 줄 기록 (+ 금액, 사진) | `certifications` |
| 번뇌비 | 못 참았어요일 때 쓴 금액 (입력할 때는 "쓴 금액") | `certifications.spent_amount` |
| 리액션 | 인증 카드에 🍚 잘 참았다(공양미) / 🪘 아쉬워요(목탁) | `reactions` |
| 콕 | 같은 방 멤버를 찔러 인증·투표를 재촉 (인증 여부와 상관없이 언제나) | `pokes` |
| 지목 | 투표 결과 "가장 크게 흔들린 보살"로 뽑힘 | `rounds.picked_member_id` |
| 이마 톡톡 | 지목된 사람에게 친구들이 이마를 두드림 (1인당 회차에 최대 10번) | `taps` |
| 휴식 중 | 3번 연속 지목된 사람이 다음 1회 후보에서 빠지는 상태 | `room_members.resting_round_date` |
| 공양미 | 개인 재화. 단위 "석". '포인트'·'출금'·'인출' 표현 금지 | `rice_histories` |
| 공양미 한 솥 | 방 공동 진행도 (300석). 가득 차면 멤버 전원 +30석 | `room_pots` |
| 쌀가마 배지 | 한 솥을 채운 횟수 (🌾×n) | `rooms.pot_completed_count` |
| 이마 방어권 | 지목돼도 톡톡을 막는 소모품 | `defense_tickets` |
| 떠난 보살 | 방을 나가거나 탈퇴한 사람의 기록을 익명으로 보여줄 때 쓰는 표시 | |

## 핵심 수치

| 항목 | 값 |
|---|---|
| 방 최대 인원 | 방을 만들 때 2~4명 중 설정 |
| 투표가 열리는 최소 인원 | 3명 (투표 명단 기준) |
| 공양미가 쌓이는 최소 인원 | 2명 (방 인원 기준) |
| 한 사람이 참여할 수 있는 방 | 최대 2개 |
| 방 이름 | 1~12자, 한글(완성형)·영문·숫자·띄어쓰기 (띄어쓰기도 1자) |
| 닉네임 | 1~8자, 한글(완성형)·영문·숫자 (띄어쓰기·특수문자·이모지·자모 단독 불가) |
| 한 줄 기록 | 1~40자, 띄어쓰기·이모지 포함 |
| 쓴 금액 | 1 ~ 999,999원 (못 참았어요일 때 필수) |
| 사진 | 인증당 0~1장, 암호화 저장, 투표 회차가 끝나고 7일 뒤 삭제 (투표 없는 회차는 투표 없음 확정 시각부터 7일 뒤) |
| 인증 수정·삭제 | 인증 후 10분 (투표가 시작되면 즉시 잠금) |
| 인증 마감 | 다음 날 05:00 (전원 인증 시 그 순간 투표 시작) |
| 투표 마감 | 투표권 있는 명단 멤버 전원이 투표하면 즉시. 아니면 다음 회차 투표가 열릴 때 닫히고 톡톡 없음 |
| 인증 보상 | 개인 +10석, 한 솥 +10석 (방마다 회차당 1번) |
| 투표 보상 | 개인 +5석, 한 솥 +5석 (방마다 회차당 1번, 모두 보살을 골라도 지급, 투표권은 인증한 멤버만) |
| 한 솥 | 300석 고정, 가득 차면 멤버 전원 +30석, 넘친 석은 이월 |
| 이마 톡톡 | 1인당 회차에 1세트 10번, 다음 투표가 열리기 전까지 |
| 연속 지목 휴식 | 3번 연속 → 다음 1회 후보 제외 |
| 이마 방어권 | 100석, 최대 1개 보유, 주 1번 사용 (월~일, 방 2개 합쳐서) |
| 꾸미기 아이템 | 6종, 50석·100석, 슬롯 1개(머리 위) |
| 탈퇴·나가기 후 남는 기록 | 6개월 뒤 사진·한 줄·금액 자동 삭제, 투표 결과는 "떠난 보살"로 유지 |

## 시간 기준

- 모든 시간은 **KST**
- 기준은 **회차 날짜** 하나: 공양미 적립, 콕 푸시·초기화, 지목 횟수, 연속 지목, 방어권 주 1회, 월 집계 모두 회차 날짜 기준
  - 예) 11/30 회차 투표가 12/1에 끝나도 11월 지목으로 집계
- 월 집계(이번 달 지목·참은 횟수·캘린더)는 매달 1일, 주 집계(방어권)는 월~일
- 투표 중이어도 05:00가 지나면 다음 회차 인증이 열림 → **한 방에서 회차 두 개가 동시에 진행될 수 있음** (어제 회차 투표 중 + 오늘 회차 인증 중). 다음 회차 투표가 열리면 이전 회차 투표는 닫히므로 투표 중인 회차는 방마다 하나뿐이고 결과는 회차 날짜 순서로 나옴 [11/8 회의]
- 인증 등록 시각이 05:00를 넘기면 등록 시각 기준으로 다음 회차에 들어감 (지난 회차는 "인증 안 함"). 05:00 전 등록은 전날 회차 [11/8 회의]

### 하루 흐름

| 시각 | 서버 동작 |
|---|---|
| 05:00 | 그 전 회차 투표가 아직 열려 있으면 닫음 (톡톡 없음) · 전날 회차 투표 시작 (전원 인증으로 이미 시작했으면 생략) · 오늘 회차 인증 시작 |
| 08:00 | 투표 독려 알림 (아직 투표 안 한 명단 멤버, 투표권 없는 미인증 멤버 포함) |
| 22:00 | 인증 마감 리마인드 (아직 인증 안 한 멤버, 방 2개면 하나로 합침). 시각 유지는 [미정] Q-58 |
| 수시 | 전원 인증 (나가기·내보내기로 전원 인증 상태가 될 때 포함) → 이전 회차 투표가 열려 있으면 닫고 즉시 투표 시작 + 투표 열림 알림 / 투표권 있는 명단 멤버 전원 투표 → 즉시 마감 |

## 회차 상태

| 상태 | 시작 | 끝 |
|---|---|---|
| 인증 중 | 회차 날짜 05:00 | 전원 인증 또는 다음 날 05:00 중 빠른 쪽 |
| 투표 중 | 인증 중이 끝남 | 투표권 있는 명단 멤버 전원 투표 또는 다음 회차 투표 시작 중 빠른 쪽 |
| 발표 | 서버 집계 완료 | - |
| (투표 없음) | 투표 시작 시점 명단이 3명 미만 | - |

| 행동 | 인증 중 | 투표 중 | 발표 후 |
|---|---|---|---|
| 인증 | ✅ | ❌ (다음 회차로) | ❌ (다음 회차로) |
| 인증 수정·삭제 | 인증 후 10분만 | ❌ | ❌ |
| 콕 | ✅ 본인 뺀 전원 | ✅ | ✅ |
| 리액션 | ✅ | ❌ | ❌ |
| 방어권 사용 | ✅ 그 방에서 인증한 뒤 | ❌ (마지막 인증자 예외) | ❌ |
| 투표 | ❌ | ✅ 명단에 있고 인증한 사람 | ❌ |
| 입장 | ✅ 이번 회차부터 | ✅ 다음 회차부터 | ✅ |
| 나가기 | ✅ | ✅ (결과에는 반영) | ✅ |
| 내보내기 | ✅ | ❌ | ✅ |

- "전원" = 그 시점 방 멤버 모두 (그날 들어온 사람·휴식 중인 사람 포함)
- 다음 회차 투표가 열리면(전원 인증 또는 05:00) 이전 회차 투표는 미투표자가 남아 있어도 그 시점에 닫음. 명단 전원이 투표하지 않은 투표라 이마 톡톡이 없음. 결과를 어떻게 처리할지는 [미정] Q-56 [11/8 회의]
- **투표 명단** = 투표 시작 시점의 방 멤버 (스냅샷). 이 중 투표 시작 시점까지 인증한 멤버만 **투표권**이 있음. 미인증 멤버는 후보로만 남음 [11/8 회의]
- 조기 마감의 **명단 전원 투표**는 남은 명단 멤버 중 투표권 있는 사람 전원이 투표한 상태. 투표하지 않고 나간 사람은 기권으로 보고 기다리지 않음 (기획 확정)
- 투표가 시작되면 그 회차의 모든 인증·리액션 잠금
