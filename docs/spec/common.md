# 공통 규칙

모든 기능 명세에 공통으로 적용되는 용어, 수치, 시간 기준, 회차 상태입니다.

## 서비스 개요

- 친구 2~4명이 방을 만들어 매일 "오늘 참았는지"를 인증하고, 인증한 친구끼리 "가장 크게 흔들린 보살"을 익명 투표로 뽑는 절약 챌린지
- 뽑힌 사람은 친구들에게 **이마 톡톡**(벌칙 연출)을 받음
- 인증·투표로 **공양미**(단위: 석)를 모아 꾸미기 아이템이나 **이마 방어권**을 삼
- 토스 앱 안의 미니앱(앱인토스)으로 출시. 로그인·약관 동의 화면 없이 토스의 익명 사용자 식별키로 사용자를 구분

## 용어

| 용어 | 뜻 | 서버 |
|---|---|---|
| 보살 | 방 안에서의 내 캐릭터. 방마다 닉네임·색상이 다름 | `room_members` |
| 회차 | 방 하나의 하루. 회차 날짜는 03:00부터 다음 날 02:59까지 (KST). 예) 6/1 02:59 인증은 5/31 회차 | `rounds` |
| 인증 | 회차마다 "참았어요 / 못 참았어요" + 한 줄 기록 (+ 금액, 사진) | `certifications` |
| 번뇌비 | 못 참았어요일 때 쓴 금액 (입력할 때는 "쓴 금액") | `certifications.spent_amount` |
| 리액션 | 인증 카드에 🍚 잘 참았다(공양미) / 🪘 아쉬워요(목탁). 처음 남기면 +1석 | `reactions` |
| 콕 | 같은 방 멤버를 찔러 인증·투표를 재촉 (인증 여부와 상관없이 언제나) | `pokes` |
| 지목 | 투표 결과 "가장 크게 흔들린 보살"로 뽑힘 | `rounds.picked_member_id` |
| 이마 톡톡 | 지목된 사람에게 친구들이 이마를 두드림 (1인당 회차에 최대 10번) | `taps` |
| 번뇌 | 지목된 사람이 받은 톡톡 횟수만큼 수행하는 것 (구 '이마 톡톡 당하기') | |
| 휴식 중 | 3번 연속 지목된 사람이 다음 1회 후보에서 빠지는 상태 | `room_members.resting_round_date` |
| 공양미 | 개인 재화(곳간). 단위 "석". '포인트'·'출금'·'인출' 표현 금지 | `rice_histories` |
| 공양미 한 솥 | 방 공동 진행도(팀 공양미). 방 목표 석(300~700석)을 채우면 멤버 전원이 목표의 10%를 받고 방 기간이 끝남 | `room_pots` |
| 쌀가마 배지 | 한 솥 목표를 채운 횟수 (🌾×n) | `rooms.pot_completed_count` |
| 이마 방어권 | 지목돼도 톡톡을 막는 소모품 | `defense_tickets` |
| 떠난 보살 | 방을 나가거나 탈퇴한 사람의 기록을 익명으로 보여줄 때 쓰는 표시 | |

## 핵심 수치

| 항목 | 값 |
|---|---|
| 방 최대 인원 | 방을 만들 때 2~4명 중 설정 |
| 투표가 열리는 최소 인원 | 3명 (투표 명단 기준) |
| 공양미가 쌓이는 최소 인원 | 2명 (방 인원 기준) |
| 한 사람이 참여할 수 있는 방 | 최대 2개 |
| 방 이름 | 1~8자, 한글(완성형)·영문·숫자·띄어쓰기 (띄어쓰기도 1자) |
| 닉네임 | 1~8자, 한글(완성형)·영문·숫자 (띄어쓰기·특수문자·이모지·자모 단독 불가) |
| 한 줄 기록 | 1~40자, 띄어쓰기·이모지 포함 |
| 쓴 금액 | 1 ~ 999,999원 (못 참았어요일 때 필수) |
| 사진 | 인증당 0~1장, 암호화 저장, 투표 회차가 끝나고 7일 뒤 삭제 (투표 없는 회차는 투표 없음 확정 시각부터 7일 뒤) |
| 인증 수정·삭제 | 인증 후 10분 (투표가 시작되면 즉시 잠금) |
| 인증 시작 | 이전 회차 투표가 마감되는 즉시 (늦어도 15:00). 이전 회차 투표가 없으면 바로 |
| 인증 마감 | 다음 날 03:00 (전원 인증 시 그 순간 투표 시작) |
| 투표 시간 | 전원 인증 또는 다음 날 03:00에 시작, 늦어도 다음 날 15:00에 마감 |
| 투표 마감 | 투표권 있는 명단 멤버 전원이 투표하면 즉시. 아니면 다음 날 15:00 자동 마감 (결과·톡톡은 똑같이 진행) |
| 인증 보상 | 개인 +10석, 한 솥 +10석 (방마다 회차당 1번) |
| 투표 보상 | 개인 +5석, 한 솥 +5석 (방마다 회차당 1번, 모두 보살을 골라도 지급, 투표권은 인증한 멤버만) |
| 톡톡 완료 보상 | 개인 +5석, 한 솥 +5석 (회차당 1번, 1번 이상 쳤을 때) |
| 리액션 보상 | 개인 +1석, 한 솥 +1석 (인증 1건당 처음 1번) |
| 번뇌 완료 보상 | 개인 +10석만 (지목된 사람, 방어하면 없음) |
| 한 솥 | 방 목표 석 300~700석 (50석 단위). 채우면 멤버 전원에게 목표의 10% 개인 지급. 연장하면 같은 목표로 다시 채우고 넘친 석은 이월 |
| 방 나가기 | 목표를 채우기 전에 나가면 그 방에서 모은 개인 공양미 차감 (잔액은 0석까지만) |
| 이마 톡톡 | 1인당 회차에 1세트 10번, 다음 투표가 열리기 전까지 |
| 연속 지목 휴식 | 3번 연속 → 다음 1회 후보 제외 |
| 이마 방어권 | 100석, 보유 개수·사용 횟수 제한 없음. 지목된 사람이 결과를 처음 본 때부터 2분 안 |
| 꾸미기 아이템 | 슬롯 3칸(모자·얼굴·표정). 목록과 가격은 최신 디자인 기준 데이터 |
| 탈퇴·나가기 후 남는 기록 | 6개월 뒤 사진·한 줄·금액 자동 삭제, 투표 결과는 "떠난 보살"로 유지 |

## 시간 기준

- 모든 시간은 **KST**
- 기준은 **회차 날짜** 하나: 공양미 적립, 콕 푸시·초기화, 지목 횟수, 연속 지목, 월 집계 모두 회차 날짜 기준
  - 예) 11/30 회차 투표가 12/1에 끝나도 11월 지목으로 집계
- 월 집계(이번 달 지목·참은 횟수·캘린더)는 매달 1일
- 다음 회차 인증은 이전 회차 투표가 마감되는 즉시 열림. 15:00 자동 마감이면 그 직후, 전원 투표로 일찍 마감되면 그 즉시. 이전 회차 투표가 없으면(처음 만든 방, 투표 명단 3명 미만인 회차) 마감된 것으로 보고 바로 엶 [Q-82]
  - 03:00 전에 이전 회차 투표가 마감될 때 다음 회차 인증을 언제 여는지는 [미정] Q-95
- 그래서 **한 방에서 회차 두 개가 동시에 진행되지 않음**. 투표 중인 회차는 방마다 하나뿐이고 결과는 회차 날짜 순서로 나옴 [Q-17]
- 인증 등록 시각이 03:00 전이면 전날 회차, 03:00 이후면 그날 회차. 그날 회차 인증이 아직 열리지 않았으면 거부 (CERT-01)

### 하루 흐름

예) 11/10 회차

| 시각 | 서버 동작 |
|---|---|
| 11/10 15:00까지 | 11/9 회차 투표가 마감되면 11/10 회차 인증 열림 |
| 11/10 20:30 | 인증 독려 알림 (아직 인증 안 한 멤버, 방 2개면 하나로 합침) [Q-58] |
| 11/11 03:00 | 11/10 회차 인증 마감 · 투표 시작 (전원 인증으로 이미 시작했으면 생략). 명단 3명 미만이면 투표 없음으로 확정하고 11/11 회차 인증을 바로 엶 |
| 11/11 08:00 | 투표 알림 (대상은 [미정] Q-96) |
| 11/11 15:00 | 11/10 회차 투표가 아직 열려 있으면 자동 마감 → 결과 판정·발표·결과 알림 → 11/11 회차 인증 열림 |
| 수시 | 전원 인증 (나가기·내보내기로 전원 인증 상태가 될 때 포함) → 즉시 투표 시작 / 투표권 있는 명단 멤버 전원 투표 → 즉시 마감 → 결과 발표·결과 알림 → 다음 회차 인증 열림 |

## 회차 상태

| 상태 | 시작 | 끝 |
|---|---|---|
| 인증 중 | 이전 회차 투표 마감 (이전 투표가 없으면 바로) | 전원 인증 또는 다음 날 03:00 중 빠른 쪽 |
| 투표 중 | 인증 중이 끝남 | 투표권 있는 명단 멤버 전원 투표 또는 다음 날 15:00 중 빠른 쪽 |
| 발표 | 서버 집계 완료 | - |
| (투표 없음) | 투표 시작 시점 명단이 3명 미만 | - |

| 행동 | 인증 중 | 투표 중 | 발표 후 |
|---|---|---|---|
| 인증 | ✅ | ❌ (다음 회차는 투표 마감 뒤) | ❌ (다음 회차로) |
| 인증 수정·삭제 | 인증 후 10분만 | ❌ | ❌ |
| 콕 | ✅ 본인 뺀 전원 | ✅ | ✅ |
| 리액션 | ✅ | ❌ | ❌ |
| 방어권 사용 | ❌ | ❌ | ✅ 지목된 본인, 결과를 처음 본 뒤 2분 |
| 투표 | ❌ | ✅ 명단에 있고 인증한 사람 | ❌ |
| 입장 | ✅ 이번 회차부터 | ✅ 다음 회차부터 | ✅ |
| 나가기 | ✅ | ✅ (결과에는 반영) | ✅ |
| 내보내기 | ✅ | ❌ | ✅ |

- "전원" = 그 시점 방 멤버 모두 (그날 들어온 사람·휴식 중인 사람 포함)
- 15:00에 자동 마감된 투표도 전원 투표로 마감된 투표와 똑같이 결과를 판정·발표하고 이마 톡톡을 진행함. 미투표자는 기권 [Q-56]
- **투표 명단** = 투표 시작 시점의 방 멤버 (스냅샷). 이 중 투표 시작 시점까지 인증한 멤버만 **투표권**이 있음. 미인증 멤버는 후보로만 남음 [11/8 회의]
- 조기 마감의 **명단 전원 투표**는 남은 명단 멤버 중 투표권 있는 사람 전원이 투표한 상태. 투표하지 않고 나간 사람은 기권으로 보고 기다리지 않음 (기획 확정)
- 투표가 시작되면 그 회차의 모든 인증·리액션 잠금
